# 🎓 Student Performance Predictor

A simple, responsive, and educational web application built using HTML, CSS, and JavaScript to predict a student's academic performance based on study hours, attendance, previous marks, and learning goals.

---

## 📌 Project Overview

The Student Performance Predictor helps students estimate their academic performance by analyzing important academic factors. Users can enter their personal and study details to receive an estimated score, expected grade, performance level, and personalized study recommendations.

It allows users to:

- Enter personal and academic details
- Predict expected academic performance
- Calculate estimated percentage and grade
- View performance level
- Receive personalized study recommendations

## 📖 How It Works

1. Enter your Name and Email.
2. Fill in your academic details such as Age, Gender, Study Hours, Attendance, Previous Marks, and Learning Goal.
3. Click **Predict Performance**.
4. The application calculates your predicted percentage.
5. It displays your expected grade, performance level, and personalized study recommendations.
